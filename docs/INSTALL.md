# 安装与使用

## 1. 安装

1. 确认手机是 ARM64、Android 8 或更新版本，并预留至少 6 GB 空间。
2. 在 [Releases 下载页](https://github.com/mzbgq29-ui/WhaleTalk-Android/releases/latest) 下载 APK ZIP，解压后点击 APK。首次从文件管理器安装时，按 Android 提示允许该来源安装应用。
3. 鲸语使用独立包名，可以与旧应用并存。启动鲸语前请先停止旧应用的服务。
4. 需要迁移时，先在旧应用的「备份与恢复」导出备份，再在鲸语中导入。不同包名的数据不会自动共享。

## 2. 首次准备

打开应用，在「运行」页选择「开始设置」，启动环境准备并等待完成。应用会在自己的私有空间准备运行层，不需要你安装 Termux 或手动配置 Linux。首次准备需要时间；不要在准备过程中清除应用数据。完成后按页面提示启动服务。

如准备失败，进入「运行日志」，查看「运行环境」和「桌面」分类中的最近失败记录。先检查可用空间，再重试；故障处理见 [排障指南](TROUBLESHOOTING.md)。

## 3. 配置模型 API

1. 打开「云端模型」，查看页面内教程。填写你的 API 服务商提供的兼容地址、API Key 和模型 ID。例如 DeepSeek 的兼容地址可填 `https://api.deepseek.com/v1`；模型 ID 以服务商当前提供的名称为准。
2. 点击「获取模型列表」并选择模型；如果服务商不提供列表接口，可手动填写模型 ID。
3. 点击「查看改动」，根据页面显示的影响选择应用方式。更换模型、地址或密钥时会先验证连接，测试可能产生少量费用。不要将 API Key 发到 Issue 或聊天群。

需要登录 AstrBot 管理界面时，打开「本机管理账号」，点击「填入初始密码」。忘记密码可在同一页面重置。旧版的恢复步骤见 [AstrBot 管理登录排障](TROUBLESHOOTING.md#astrbot-初始密码找不到或重置后无法登录)。

## 4. 登录 QQ 并设置回复范围

打开「连接 QQ」，启动 QQ 服务，在登录画面扫码，并在手机 QQ 中确认；如有安全验证，按 QQ 自己的提示完成。扫码成功后还需等待消息通道连接。

到「回复规则」填写允许的好友或群，并选择适合的预设。群聊按所选规则可能需要 @ 机器人；新安装默认唤醒词为「鲸语」。可先用页面内的「回复规则试算」检查草稿，再点「查看改动」保存。用**另一个账号**发送消息验证收发，`#sl` 可用于查看状态。没有回复时可从「运行」页打开「为什么没回复？」或查看 [排障指南](TROUBLESHOOTING.md)。

服务器运行时，选择「现在应用」会短暂重启 AstrBot 加载新设置。也可以选择「下次启动时应用」，把配置留到主动启动 AstrBot 或系统恢复服务时应用。运行中的 SnowLuma 和 QQ 会保留当前会话。应用后等到「消息通道」显示「已连通」再测试收发。

## 5. 人设、插件与备份

「人设 → 人设仓库」可浏览内置角色、收藏或导入酒馆 PNG/JSON 卡，预览后选择导入并应用。导入到机器人需本机服务已启动；角色卡脚本和变量面板不运行，世界书作为静态参考。

「工具」中可管理插件和知识库。请只安装你信任的扩展；某些知识库向量功能需要自行配置嵌入模型。更换设备或包名前，在「备份与恢复」中导出备份，并把它保存在私人位置：备份可能包含敏感设置。

## 6. 后台运行

按应用「后台运行」页面及手机系统提示，允许必要的通知和后台活动。不同厂商的省电策略不同，后台被系统停止时可重新打开应用并启动服务。
