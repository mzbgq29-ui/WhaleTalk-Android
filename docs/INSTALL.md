# 安装与使用

## 1. 安装

1. 确认手机是 ARM64、Android 8 或更新版本，并预留至少 6 GB 空间。
2. 下载项目提供的 APK ZIP，解压后点击 APK。首次从文件管理器安装时，按 Android 提示允许该来源安装应用。
3. 从 **1.3.7-qqfix 升级到相同签名的 1.3.8-qqfix**：先停止旧服务，再覆盖安装，保留数据。原始 `dev.bigfish.nativebot` 和 `.qqfix` 修复版包名不同，会分别安装；两个版本不要同时运行服务。
4. 更名后的仓库源码目前没有发布新的 APK。自行签名的包若与现有 APK 签名不同，不能覆盖安装；请先在现有应用中导出并安全保存备份。

## 2. 首次准备

打开应用，进入「安个家」或准备环境引导，启动环境准备并等待完成。应用会在自己的私有空间准备运行层，不需要你安装 Termux 或手动配置 Linux。首次准备需要时间；不要在准备过程中清除应用数据。完成后按页面提示启动服务。

如准备失败，进入「运行日志」，查看「运行环境」和「桌面」分类中的最近失败记录。先检查可用空间，再重试；故障处理见 [排障指南](TROUBLESHOOTING.md)。

## 3. 配置模型 API

1. 打开「云端模型」，查看页面内教程。填写你的 API 服务商提供的兼容地址、API Key 和模型 ID。例如 DeepSeek 的兼容地址可填 `https://api.deepseek.com/v1`；模型 ID 以服务商当前提供的名称为准。
2. 点击「获取模型列表」并选择模型；如果服务商不提供列表接口，可手动填写模型 ID。
3. 点击连接测试，成功后保存。服务商可能按调用量收费，余额、模型权限及地址以服务商为准。不要将 API Key 发到 Issue 或聊天群。

## 4. 登录 QQ 并设置回复范围

打开「连接 QQ」，启动 QQ 服务，在登录画面扫码，并在手机 QQ 中确认；如有安全验证，按 QQ 自己的提示完成。扫码成功后还需等待消息通道连接。

到「回应方式」填写主人 QQ、允许的好友或群，并选择适合的预设。群聊按所选规则可能需要 @ 机器人；修改后记得保存。用**另一个账号**发送消息测试；`#sl` 可用于查看状态。没有回复时依次查看 [排障指南](TROUBLESHOOTING.md)。

## 5. 人设、插件与备份

「人设 → 人设仓库」可浏览内置角色、收藏或导入酒馆 PNG/JSON 卡，预览后选择导入并应用。导入到机器人需本机服务已启动；角色卡脚本和变量面板不运行，世界书作为静态参考。

「工具」中可管理插件和知识库。请只安装你信任的扩展；某些知识库向量功能需要自行配置嵌入模型。更换设备或包名前，在「备份与恢复」中导出备份，并把它保存在私人位置：备份可能包含敏感设置。

## 6. 后台运行

按应用「后台运行」页面及手机系统提示，允许必要的通知和后台活动。不同厂商的省电策略不同，后台被系统停止时可重新打开应用并启动服务。
