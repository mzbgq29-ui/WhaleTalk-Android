# 大肥鱼 1.3.7-qqfix 并存修复版

基于用户提供的 1.3.6 源码及完整运行资产构建，保留原作者 mzbgq 与各运行组件的许可。应用 ID 为 `dev.bigfish.nativebot.qqfix`，桌面名「大肥鱼·修复版」，版本号 100307。使用独立签名，可与旧版同时安装，数据分别保存。

## 使用

1. 安装新的 ARM64 完整 APK，首次准备环境仍会占用较大存储。
2. **先在旧版停止服务，再启动本版。** 两版默认服务端口相同；并存安装不代表可以同时启动两套服务。
3. 迁移时先在旧版「备份与恢复」导出，再在本版导入。备份可能包含个人密钥和账号设置，请自行保管，不要上传分享。
4. 本版保留 QQ 3.2.35-54395 和 SnowLuma 2.4.2。没有找到可核验的更高 ARM64 QQ 包，未虚构版本升级。详见 `QQ-SnowLuma-repair.md`。

## 减少操作步骤的功能

- **懒人回应预设**：在回应方式中选择「只和主人聊」「好友自然聊」「群聊仅 @」。只填充当前草稿，支持撤销，点击保存后才应用。主人模式清空好友和群名单，好友模式清空群名单，群聊模式保留名单并使用引用回复。不会自动发消息，也不会自动扩大允许名单。
- **日志搜索与错误筛选**：在最近 200 行中搜索关键词、只看警告 / 错误、复制当前结果。导出日志仍保留完整上下文；暂停时切换分类也会正确加载该分类。
- **本机连接自检**：在快速排障页手动检测本机思考引擎和 QQ 管理服务，显示耗时或未监听的提示。当端口有响应而本应用服务未运行时，提示检查旧版或其他应用占用。TCP 连接成功只证明监听存在，不能证明 QQ 登录或 OneBot 收发成功。
- **并存版迁移入口**：关于页面提示旧版停服与备份迁移方式。
- **QQ 快捷指令**：使用指南中一键复制 `/help`、`/new`、`/reset`、`/sid`，粘贴到 QQ 自行发送，适合不想记命令时使用。

## 已知验证边界

构建、自动化检查、签名与资源校验的最终结果以同批交付的验证记录为准。未连接 ARM64 手机或真实 QQ 账号，不能承诺所有手机无问题，也不能把本机握手通过当作真实登录和消息收发通过。新签名仅用于这个独立安装版本，不能覆盖原作者签名的旧版。
