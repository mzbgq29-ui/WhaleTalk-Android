# 鲸语 1.2 · mzbgq

应用作者：mzbgq。

这一版以 `BigFishStudioActivity` 作为唯一的产品界面宿主，导航、表单、卡片、账号连接、工具和维护页面由 Studio 系列文件实现。旧 Activity 名仅作为兼容历史快捷方式和通知的别名，均指向新界面，不再启动原安卓版的管理页面。

底部导航为鲸鱼、聊天、工具、我的。子页面包含初次设置、云端模型、QQ 连接、回应方式、人设、聊天记录、会话、插件、知识库、定时任务、用量、日志、备份、存储、后台、外观、本机账号、许可、终端及扩展服务。机器人相关管理通过本机 API 完成，正常操作不加载 AstrBot 的网页前端。

运行组件继续复用既有开源运行层、PRoot、AstrBot、NapCat、Linux QQ 等。源码与第三方声明保留相应原作者；应用界面作者名不替代底层组件的署名。

## 玻璃修复

- 玻璃采样来源只包含装饰背景，不包含界面文字。
- 浮动面板先绘制不透明底层，防止布局初帧、采样层未就绪或窗口变化时透出下方内容。
- 文字和操作按钮位于独立前景；按钮不再重复采样和折射。
- 关闭色散与深度增强，折射边缘按实际面板大小收敛。
- Material 弹窗、输入框及菜单使用不透明容器。
- 新增针对后层文字穿透、采样不可用时的降级、弹窗前景的定向渲染回归检查。

Android 13 及以上使用折射效果，Android 12 使用模糊，Android 8–11 使用玻璃配色与边缘高光。

## 验证范围

本次用户重新授权检查玻璃重影问题，因此针对玻璃进行渲染检查。完整 QQ 实号登录和云端模型调用仍需要用户账号、服务商配置和实机运行；构建成功不能替代这些验收。
